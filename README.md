# aoBudgetAI

**Decentralized. Intelligent. Yours.**

aoBudgetAI is a budget tracker built on the **ao** computer and the **Arweave Permaweb**. It leverages AI to provide powerful financial insights—like pattern recognition, predictive analytics, and personalized recommendations—while guaranteeing true data ownership and privacy. This is Web3, reimagining a core Web2 service.

## 🚀 Overview

Traditional budgeting apps sell your data. aoBudgetAI protects it. By processing data with AI agents on ao computer and storing results on Arweave, we give you a powerful financial co-pilot that works for you, and only you.

### ✨ Features

**🔐 User-Centric Design:** Built on a foundation of decentralization, putting your control first.
**🤖 AI-Powered Insights:**
**Pattern Recognition:** Automatically categorizes on/off-chain spending.
**Predictive Analytics:** Forecasts cash flow and warns of future shortfalls.
**Personal Recommendations:** Gets actionable, hyper-personalized financial advice.
**💸 Innovative Monetization:** Freemium model powered by **aostore**. Use for free with ads, or stake USDC (yield pays for your subscription).
**🌐 Permanence:** The app and your insights live on the Permaweb.

## 📦 Installation & Setup

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/aoBudgetAI.git
   cd aoBudgetAI
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Run the development server**

   ```bash
   npm run dev
   ```

   Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

## 🧠 How It Works (The Flow)

1. **User connects** their wallet.
2. **Financial data** is fetched from ao processes
3. **Data is sent** as a message to the AI **ao Process** for AI analysis.
4. The **AI Agent** on ao processes and analyzes the data.
5. The results (insights, predictions) are returned and Shown to the User
6. The frontend fetches and displays this processed, insightful data.
